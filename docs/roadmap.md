## Новые фичи

### Статистика и графики

Частота посещений по неделям/месяцам. Тренды: «В этом месяце вы ходили реже на 30%». Прогноз: «При таком темпе абонемент закончится к...». Календарная карта активности.

### Типы абонементов

По времени (30 дней, 90 дней) — не по занятиям. Безлимитные на период. Абонементы с заморозкой.

### Экспорт/Импорт

JSON/CSV export. Бэкап localStorage → файл. Восстановление из файла.

### Напоминания

Push-уведомления через Service Worker: «Давно не были в зале!».

### Совместные абонементы

Несколько человек на одном абонементе. Кто сколько раз сходил.

### Шаблоны абонементов

Быстрое создание по пресетам: «Тренажёрка 12», «Бассейн 8» и т.д.
