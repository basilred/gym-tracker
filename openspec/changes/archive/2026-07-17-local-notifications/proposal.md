## Why

Сейчас данные хранятся в localStorage, что не позволяет Service Worker читать их для push-уведомлений. Нужно перейти на IndexedDB как единый источник правды и добавить систему локальных уведомлений о состоянии абонементов.

## What Changes

- Замена `localStorage` на IndexedDB в модуле `useSubscriptions`
- Миграция существующих данных из localStorage при первом запуске
- Notification API с проверками при открытии PWA:
  - «Давно не были» — больше N дней без посещения
  - «Абонемент закончен» — все сессии использованы
  - «Скоро закончится» — осталось ≤ 2 сессий
  - «Прогресс» — 50%/100% от абонемента
- React-хук `useNotifications` с проверками при монтировании и подпиской на изменения
- Страница/блок настроек уведомлений (включить/выключить, порог дней)

## Capabilities

### New Capabilities
- `notification-settings`: UI и логика для настройки уведомлений (вкл/выкл, порог дней)
- `notification-rules-engine`: Детекторы состояний (давно не был, закончен, скоро закончится, прогресс) и правила показа
- `indexeddb-storage`: Модуль хранения данных на IndexedDB с миграцией из localStorage

## Impact

- **Хранилище**: `useSubscriptions` полностью заменяет localStorage на IndexedDB. Все тесты модуля переписываются под `fake-indexeddb`.
- **Зависимости**: Добавляется `idb` (npm), `fake-indexeddb` (devDependencies).
- **UI**: Новая страница/модалка настроек уведомлений.
- **Миграция**: Существующие пользователи получат автоматическую миграцию при первом запуске — данные копируются из localStorage в IndexedDB.
